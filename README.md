# Razi's Digital Canvas

Build a Premium Personal Portfolio Website for Mohd Razi Chaudhary

Create a modern, professional, aesthetic, minimalistic personal portfolio website for Mohd Razi Chaudhary, a second-year B.Tech Artificial Intelligence & Machine Learning student.

The website should feel like a real developer portfolio, not an AI-generated template.

1. Overall Design Direction

Design language:

* Professional
* Minimalistic
* Premium
* Modern
* Tech-focused
* Clean
* Subtle futuristic/AI aesthetic
* Glassmorphism
* Strong typography
* Lots of whitespace
* Smooth micro-interactions
* High-quality animations
* Fully responsive

Color Palette

Use a sophisticated combination of:

* Deep navy / dark blue
* Electric blue
* Soft purple
* White
* Very light blue/lavender gradients

Avoid making the website overly colorful.

The primary visual identity should be:

Blue → Purple → White

Use gradients sparingly for highlights, buttons, borders, glows and backgrounds.

Suggested visual feel:

* Background: near-white or very dark navy depending on section/theme
* Primary: electric blue
* Secondary: purple
* Text: dark navy / white
* Accent: blue-purple gradient

Implement a dark/light theme toggle if it can be done cleanly.

13. Glassmorphism System

Use glassmorphism throughout the website, but DON’T overuse it.

Glass cards should have:

* translucent backgrounds
* backdrop blur
* subtle borders
* soft shadows
* subtle blue/purple glow
* rounded corners

Example visual characteristics:

Use varying levels of transparency so the cards don’t look like identical boxes.

Add subtle gradient borders on important cards.

Avoid excessive neon effects.

The result should feel like a premium SaaS/developer website, not a gaming website.
